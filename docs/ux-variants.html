Today: 7 fields, all typed by hand

  1. Forge picker, even though GitLab is already connected
  2. Base URL typed again
  3. Search box that needs a separate Search button
  4. Local clone path typed as text, with no folder picker and no check that it exists
  5. Target branches typed as comma-separated globs
  6. Posting mode chosen with no explanation
  7. Poll interval

All variants fix these

  1. Forge and URL come from the connection you already made
  2. Your projects list loads at once, sorted by recent activity, and filters as you type
  3. Warden finds your existing clone by matching git remotes, or clones a copy itself
  4. Branches come from GitLab: the default branch plus protected branches
  5. Safe defaults (Draft, every 5 min). Change them later on the project page
